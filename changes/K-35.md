# K-35 — đường triển khai prod chạy được bằng "bó phát hành" (đóng L5-N01, L5-N07)

- `deploy/scripts/bundle.sh` (mới): tar.gz giữ cấu trúc repo của `deploy/compose/{base,prod}.yml`, `deploy/minio/`,
  `deploy/scripts/`, `deploy/backup/` (bỏ `tests/`, `__pycache__/`). Dùng `tar` trên cây checkout thay `git archive`
  của plan: container verify không có `.git`, CI checkout đúng sha nên cây = commit.
- `deploy.yml`: staging/production dựng bó, scp một tệp, giải nén vào `/opt/appback/releases/<tag>/`, chạy
  `deploy.sh` của chính bó; rollback gọi `releases/<tag>/deploy/scripts/rollback.sh`.
- `lib.sh`: tự nạp `COMPOSE_ENV_FILES=/etc/appback/appback.env,/opt/appback/release.env` (chỉ tệp đang có) và đọc biến
  script cần (`COMPOSE_PROFILES`, `APPBACK_BASE_URL`, `IMAGE_REGISTRY`…) từ appback.env khi người gọi chưa đặt;
  `select_release` (compose của `releases/<tag>`), `assert_env_ready` (thiếu appback.env / có `IMAGE_TAG=` → thoát 2),
  `assert_release_env`, `load_app_services` (= `docker compose config --services` trừ hạ tầng/migrate/api),
  `swap_services` (thay `swap_workers`: worker, beat, web, ml, ml-train…), `bootstrap_infra` (L5-N01),
  `record_release` (release.env + symlink `current` bằng rename nguyên tử + current_tag). Giá trị người gọi đặt
  (drill.sh) giữ nguyên.
- `deploy.sh`: pull → dựng hạ tầng → migrate → publish → swap api → swap dịch vụ → smoke → ghi release; hỏng thì gọi
  rollback.sh của bản trước. `rollback.sh`: compose của `releases/<tag>`, đổi cả web/ml.
- `backup.sh`, `restore.sh` (L5-N07): bỏ mặc định `COMPOSE_FILE` riêng, dùng lib; kiểm appback.env + release.env trước
  mọi lệnh docker; `restore.sh` bật lại `api` + `load_app_services`.
- systemd: `ExecStart=/bin/bash /opt/appback/current/deploy/...` (bó giữ mode 644 — exec trực tiếp sẽ hỏng).
- README §1/§9/§10/§12 + bảng biến. Test: `test_deploy.py`, `test_rollback.py`, `test_workflows_deploy.py`,
  `test_backup.py`, `test_restore.py`, `support.py` (docker giả dùng chung `FAKE_DOCKER`).
- Không đổi API, DB, migration, hợp đồng FE–BE.
