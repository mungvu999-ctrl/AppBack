  1. `effective == "human"` → `userCalibrated, ()`: ca `human`.
  2. `effective == "none"` → `None, ()`: ca `no-scale`.
  3. `project_default` hoặc `basis == "default"` → `unresolved, ("projectDefault",)`: ca `default`.
  4. `stored == "human"` (tầng pipeline nhưng bản lưu là human, tức trang đổi) → `unresolved, ("pageChanged",)`: ca `page-changed`.
